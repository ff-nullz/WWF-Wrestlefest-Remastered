# Building wfengine

```
./build.sh            # bump src/version.h (WF_VERSION += 1), then make
./build.sh --no-bump  # plain make, no bump
make regress          # selftest digest vs baseline.txt (run after ./build.sh)
make baseline         # refresh baseline.txt — only after eyeballing the change
```

The build number is the single source of "which binary is this":

- CLI: `wfengine Vnnn` on stderr at start-up (`src/main.c`)
- window title: `WrestleFest native Vnnn`
- on-screen label `Vnnn` (`src/video.c`)

`src/version.h` is generated by `build.sh` and checked in; commit the bump
together with the change it belongs to. Rule set by the user 2026-08-23:
never build with a bare `make`.
